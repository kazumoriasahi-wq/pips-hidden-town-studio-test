# PIP’S HIDDEN TOWN — Three Little Stories

Studio edition now contains three richly illustrated chapters, each with five fixed differences:
1. The Apricot Bakery / アプリコット・ベーカリー
2. The Glasshouse Florist / 花屋の温室
3. The Stargazer’s Attic / 星見の屋根裏

Start locally with `node serve.cjs`, then open http://127.0.0.1:4202/?lang=ja . Run validation with `node test.cjs`. No packages required.

Choose any chapter on the town guide. Discoveries and completion are saved separately for each chapter. A completed chapter leads to a keepsake card and the next chapter. Restart clears only the current chapter. Existing single-chapter saves are migrated in place, retaining bakery discoveries. The original local storage key is retained; progress is not shared with the older PIP game or the other nine games.

Linked zoom views, two-step clues, untimed play, original synthesized music and sound, English/Japanese, responsive layout. Each pair shares the same original painting; only five small masks display the edited artwork. No ads, accounts or analytics.

## iPhone check
Open the published URL in Safari. Choose a chapter, scroll normally, open Look closer and drag the picture horizontally/vertically. The two views should follow each other. Find differences in either picture, use hint twice, reload and change chapters to verify independent progress. Complete all five and use the next-chapter button. Check music/mute after starting. Real iPhone testing remains for the owner; browser viewport checks are not physical-device tests.
