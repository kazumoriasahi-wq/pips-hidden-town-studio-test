# PIP’S HIDDEN TOWN — Studio edition

A new, separate single-stage edition: The Apricot Bakery. The nine earlier games and the existing PIP release are unchanged.

Run `node serve.cjs`, then open http://127.0.0.1:4202/?lang=ja . No packages required.

Five detailed changes, linked zoom views, two-step clues, untimed play, original synthesized music, Japanese/English, isolated local progress. YouTube SDK lifecycle/cloud-save adapter is included; this release has not been certified in the official Playables environment.

## Phone check
Open published URL in Safari; start; scroll both images; compare at full size and with Look closer; drag the zoom picture horizontally and vertically; tap a difference in either image; use hint twice; reload to verify progress; finish all five; restart. Tap music to mute/unmute. iPhone audio starts only after a user gesture. Real-device check is requested from the owner; browser viewport checks are not a physical iPhone test.

## Scope
One handcrafted scene with five fixed differences. Replay uses the same five changes. Additional scenes should meet this visual standard before expansion. No analytics, ads, account requirement or external audio files.
